3. **통과:** 미션 18장·평가 19장의 제목·번호가 제작 원고와 일치한다. 37장 모두 발표자 노트가 있으며 각 자료에 편집 가능한 표 8개가 있다. PPTX 패키지·슬라이드 크기 검사에서도 오류가 없다.

## 검증 범위의 구분

자동 테스트 8개 파일·62개 항목과 build·lint 통과 기록, 이전 원격 API 로그인·CRUD 검증 기록을 사용한다. 앱 소스가 바뀌지 않았다면 같은 검사를 불필요하게 반복하지 않는다.

전체 브라우저 사용 흐름과 신규 가입 확인 메일의 수신·복귀는 별도 확인 대상이다. 이 발표자료 체크리스트의 완료를 해당 기능까지 모두 재검증했다는 뜻으로 사용하지 않는다.
